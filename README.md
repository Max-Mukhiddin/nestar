# Nestar — Course Project

> **Educational repository.** Nestar was built while learning NestJS/GraphQL marketplace architecture and is kept for study/history purposes. It is **not** presented as one of my original portfolio products.

The project was used to practice modular backend architecture, GraphQL APIs, MongoDB/Mongoose, authentication, and marketplace-style domain modeling.

I later applied and substantially extended the concepts learned here when building my independent product **PawPal** with its own pet-care domain, product/service model, bookings, inquiries, messaging, notifications, security improvements, branding, and deployment.
